SLEEC-PATCH Workbench

SLEEC-PATCH is a research prototype that automatically generates, formally verifies, and ranks resolution patches for well-formedness issues in SLEEC robot normative specifications. The framework combines deterministic formal reasoning with LLM-assisted semantic refinement to produce correct-by-construction candidate repairs that preserve stakeholder intent.

Key Features

  • ✔ Detects conflicts, redundancies, concerns, purpose blocking, and situational conflicts using LEGOS-SLEEC.
  • ✔ Selects appropriate repair operators based on the diagnosed issue.
  • ✔ Generates deterministic repairs using formal rule transformations.
  • ✔ Uses an LLM only for semantic refinements requiring new concepts or rules.
  • ✔ Formally verifies every candidate patch using LEGOS-SLEEC.
  • ✔ Ranks verified patches according to specification quality criteria.
