SLEEC-PATCH Architecture

SLEEC-PATCH combines formal reasoning and LLM-assisted semantic refinement to generate, verify, and rank resolution patches for well-formedness issues in robot normative specifications.

Workflow


    

  1. Load a SLEEC specification and well-formedness properties.
    2. 

  2. State-of-the-art tooling diagnoses conflicts, redundancies, concerns, and other well-formedness issues.
    3. 

  3. Select an appropriate repair operator.
    4. 

  4. Generate repairs using formal rule transformations or semantic refinements using an LLM.
    5. 

  5. Formally verify every candidate patch with state-of-the-art verification tooling.
    6. 

  6. Rank verified patches according to criteria established with multidisciplinary stakeholders.
    7. 

  7. Present the ranked patches to stakeholders.
