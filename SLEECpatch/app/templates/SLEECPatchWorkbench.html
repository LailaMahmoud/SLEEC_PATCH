    Before you begin

    Instructions

    SLEEC-PATCH guides you through a SLEEC requirement specification, diagnoses well-formedness issues, and helps you resolve them one at a time.

    1. Choose a use case and review the system context.
    2. Start the analysis to detect conflicting or otherwise problematic requirements.
    3. Resolve the selected issue using generated patches or a manual edit.
    4. Verify each edit before proceeding to the next issue. Each issue uses the original input specification.
